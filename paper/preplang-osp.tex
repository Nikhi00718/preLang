\title{PrepLang: a data-aware compiler for data-preparation pipelines that reuses its proofs on new
batches}

\author{Nikhil V}
\ead{atnikhil06@gmail.com}
\address{School of Computer Science and Engineering, Vellore Institute of Technology, Vellore 632014,
Tamil Nadu, India}

\begin{abstract}
In batch data preparation, a pipeline is compiled when its input already exists and is then reused on
batches the compiler has never seen. \PL, a compiler written in C++17 for a small language of table and
image pipelines, exploits both facts. At compile time it reads every CSV cell, the Parquet footers and the
image headers, proves or refutes the pipeline's data contracts before any row is processed, and removes the
checks and operations that this input makes redundant. Each removal is kept in the generated pandas and
OpenCV program behind a guard holding the facts it relied on. On a new batch the program runs unchanged
unless the batch breaks those facts; the removed code then runs again, and the result is the one a fresh
compilation would give. Across \RealRuns{} later months of five public datasets, the compiled pipelines
agreed with a fresh compilation on \RealDeoptCorrectPct\% of the months and never produced a different
result. The repository includes \TestCount{} test checks with sanitizer, coverage and fuzzing jobs, Lean~4
proofs for a core of the analysis, and one script that reproduces every number reported here.
\end{abstract}
