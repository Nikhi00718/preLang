\title{PrepLang: a data-aware compiler for data-preparation pipelines that reuses its proofs on new
batches}

\author{Nikhil V}
\ead{atnikhil06@gmail.com}
\address{School of Computer Science and Engineering, Vellore Institute of Technology, Vellore 632014,
Tamil Nadu, India}

\begin{abstract}
\PL is a compiler, written in C++17, for a small language of table and image preprocessing pipelines.
It reads the input data at compile time, proves or refutes the pipeline's data contracts before any
data is processed, removes the checks and operations the data makes useless, and generates a pandas
and OpenCV program. The generated program keeps every removal behind a guard with the input facts it
depends on, so it runs unchanged on new batches and runs a removal again only on a batch that breaks
its facts. The repository also holds Lean~4 proofs for a core of the analysis, a lifter for pandas
scripts, a tool that composes compiled stages, a tool that releases differentially private facts to
compile against, and the complete evaluation.
\end{abstract}

\begin{keyword}
data-aware compilation \sep data validation \sep speculative optimization \sep deoptimization \sep
data pipelines \sep differential privacy
\end{keyword}
