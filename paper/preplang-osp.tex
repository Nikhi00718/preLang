\begin{abstract}
\PL is an open-source compiler for tabular and image preparation. It analyzes a pipeline together with
an available input batch, using CSV values, Parquet metadata and image headers. The analysis discharges
contracts it can prove, reports definite violations and retains unresolved checks for execution. The
compiler emits Python code for pandas and OpenCV and records the input facts needed by each speculative
removal. On a later batch, the generated program checks these facts and restores affected instructions;
it refuses inputs outside its admission conditions. In \RealRuns{} pipeline--batch trials across five
public datasets, using first-month and previous-month compilation anchors, reuse agreed with fresh
compilation on outputs or contract failures. Differential testing also found no disagreement for
\DiffAll{} generated tabular programs. Lean proofs establish correctness for a restricted language core;
the C++ implementation is tested, not formally verified. The software includes a pandas-prefix translator,
diagnostics, examples and scripts for inspecting and reproducing the evaluation.
\end{abstract}
