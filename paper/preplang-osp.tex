\title{PrepLang: a data-aware compiler for data-preparation pipelines that reuses its proofs on new
batches}

\author{Nikhil V}
\ead{atnikhil06@gmail.com}
\address{School of Computer Science and Engineering, Vellore Institute of Technology, Vellore 632014,
Tamil Nadu, India}

\begin{abstract}
A data-preparation pipeline is compiled when its input already exists, and then run again on later
batches the compiler never saw. \PL, a compiler for a small language of table and image pipelines
written in C++17, uses both facts. It reads the input at compile time (every CSV cell, Parquet footers,
image headers), proves or refutes the pipeline's data contracts before any data is processed, and
removes the checks and operations the data makes useless. Every removal stays in the generated pandas
and OpenCV program behind a guard that holds the facts about the input it depends on, so the program
runs unchanged on new batches and runs a removal again only on a batch that breaks those facts, with
the result a fresh compilation would give. The repository holds \TestCount{} unit tests with
sanitizer, coverage and fuzzing jobs, Lean~4 proofs for a core of the analysis, and one script that
reproduces every number in this article.
\end{abstract}
